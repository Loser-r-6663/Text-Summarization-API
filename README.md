# Text Summarization API

An API for text summarization built with FastAPI and the Hugging Face model
[`sshleifer/distilbart-cnn-12-6`](https://huggingface.co/sshleifer/distilbart-cnn-12-6).

## Features

The system provides an API that accepts English text and returns a summary
generated by the DistilBART model. It also provides endpoints for retrieving
service information and checking the service health.

- Python

## Installation

Create a virtual environment in the project directory:

```powershell
python -m venv .venv
```

Activate the virtual environment in Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the required dependencies:

```powershell
pip install -r requirements.txt
```

## Run the API

```powershell
uvicorn main:app --reload
```

By default, the API runs at `http://127.0.0.1:8000`. Interactive Swagger UI
documentation is available at `http://127.0.0.1:8000/docs`.

## Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/` | Returns API information |
| `GET` | `/health` | Checks the service health |
| `POST` | `/predict` | Summarizes text |

### Submit a Summarization Request

The `POST /predict` endpoint accepts a JSON body with the following fields:

| Field | Type | Default | Constraints |
| --- | --- | ---: | --- |
| `text` | string | — | Required; at least 50 characters |
| `max_length` | integer | `130` | Between 10 and 500 |
| `min_length` | integer | `30` | Between 5 and 200, and less than `max_length` |

Example request in Windows PowerShell:

```powershell
$body = @{
  text = "Artificial intelligence is transforming industries across the global economy. Machine learning helps professionals analyze data and make better decisions. Safe and ethical deployment remains important as these models become more sophisticated."
  max_length = 60
  min_length = 5
} | ConvertTo-Json

Invoke-RestMethod `
  -Uri "http://127.0.0.1:8000/predict" `
  -Method Post `
  -ContentType "application/json" `
  -Body $body
```

Example successful response (the summary text may vary depending on the model's
output):

```json
{
  "model_used": "sshleifer/distilbart-cnn-12-6",
  "original_length": 243,
  "summary_length": 59,
  "summary_text": "AI helps industries analyze data and make better decisions."
}
```

The API returns an appropriate error if `text` is shorter than the minimum
length, a parameter is outside its allowed range, or `min_length` is greater
than or equal to `max_length`.

## Test the API

Start the server, then open another terminal and run:

```powershell
python test_api.py
```

The script tests the `/`, `/health`, and `/predict` endpoints, including the
case where the input text is too short.
